# Bobo Reborn Repository Roadmap

A living list of ideas for making this repository a useful home for the saga. Proposed items do not become story canon just by appearing here.

## Documentation
- [x] Record core canon and timeline.
- [x] Maintain a character visual-reference gallery.
- [x] Add a detailed character roster.
- [x] Document recurring locations and running gags.
- [ ] Add a relationship map after reviewing all confirmed relationships.
- [ ] Add a glossary for recurring names, phrases, and in-universe terms.

## Story archive
- [ ] Archive finished chapters with titles and continuity notes.
- [ ] Add a story index grouped by arc.
- [ ] Mark entries as canon, alternate take, or non-canon gag where appropriate.
- [ ] Record continuity changes after major events.

## Art and media
- [ ] Add more clear character renders with source/artist credits where known.
- [ ] Distinguish creator-owned renders from fan art and temporary visual references.
- [ ] Track unknown credits without guessing the artist.
- [ ] Add vehicle reference images and restoration-stage notes when available.

## Worldbuilding
- [ ] Expand the vehicle registry as cars become established.
- [ ] Add recurring locations only when they matter to the story.
- [ ] Track important props and running gags.
- [ ] Keep new ideas jungle-focused unless a story gives a good reason to go elsewhere.

## Contribution checklist
1. Check [CANON.md](CANON.md) and [TIMELINE.md](TIMELINE.md).
2. Separate confirmed facts from open ideas.
3. Preserve character relationships and established details.
4. Credit creators accurately; if a source is unknown, say so.
5. Prefer a complete story or useful reference over empty placeholder files.
